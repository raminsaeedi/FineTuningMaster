# Overleaf Release Package

1. Upload or copy every file and directory in this folder to one Overleaf project.
2. Set `main.tex` as the main document.
3. Select **XeLaTeX** as the compiler.
4. The bibliography backend is **BibTeX**, using `natbib`, `plainnat`, and `references.bib`.
5. Compile `main.tex`; Overleaf should run XeLaTeX, BibTeX, and the required XeLaTeX reruns automatically.
6. The submission metadata, authorship declaration, AI-use disclosure, and final exploratory human-evaluation results are included. Aggregated human-evaluation evidence is documented in `HUMAN_EVALUATION_REPORT.md`; participant nicknames and tokens are intentionally excluded from the release.
